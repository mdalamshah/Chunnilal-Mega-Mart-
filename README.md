# Chunnilal Mega Mart – Next.js site

Stack: Next.js 14 (App Router) · React 18 · TypeScript · Tailwind CSS · Three.js + React Three Fiber · GSAP + ScrollTrigger · MP4/WebM video.

## Run
    npm install
    npm run dev        # http://localhost:3000
    npm run build && npm start

## Deploy (free): Vercel
Push this folder to GitHub → vercel.com → New Project → Import → Deploy (no settings needed).

## Where to edit
- `lib/products.ts` – products (replace sample art with real photos in `public/products/` and show them in `components/Catalog.tsx`)
- `lib/store.ts` – address / directions link
- `public/media/logo-intro.{webm,mp4}` – owner's logo video (intro + fixed background)
- `public/logo.png` – logo icon
- Add a verified WhatsApp number / phone only when available.
